1 Executive Summary & Platform Philosophy

Traditional online education platforms often suffer from high student abandonment and superficial content consumption. Learners frequently scrub through instructional videos or jump straight to final exams without truly internalizing prerequisite knowledge.

Progressive Learning solves this core problem by implementing an automated Mastery-Based Sequential Unlocking Engine. Instead of self-paced arbitrary navigation, knowledge is structured as an interactive milestone roadmap where each module acts as a strict cognitive prerequisite for the next.

🔒 Sequential Gating

Lesson N cannot be accessed until the student demonstrates verifiable mastery by passing Lesson N-1's quiz assessment.

⚡ Dynamic XP Economy

Every passed quiz awards 10 XP per correct question, fueling rank progression through Beginner, Intermediate, Advanced, and Expert tiers.

📊 Curriculum Telemetry

Real-time drop-off funnels and KPI analytics empower educators to pinpoint curriculum bottlenecks and optimize lesson retention.

Core Mission
Progressive Learning shifts online education from passive video watching to active retention. By enforcing verifiable mastery at every stage, students build genuine, durable competence.

2 Student Features & Learning Experience

2.1 Interactive Serpentine Learning Roadmap

Inspired by industry leaders in habit-forming education (such as Khan Academy and Duolingo), curriculum progression is visually represented as an organic, winding S-curve learning trail:

  • Completed Milestones: Illustrated with radiant emerald indicators and checkmarks representing mastered modules.
  • Current Active Lesson: Features animated dual-ring pulsating halos and a subtle floating bob, providing an unmistakable visual beacon.
  • Locked Lessons: Rendered in muted slate tones with secure lock badges, preventing unauthorized skipping.
  • Dynamic SVG Engine: Connects all nodes using mathematically calculated cubic bezier tangents (M x1 y1 C x1 cpY1, x2 cpY2, x2 y2) with animated marching dashes that guide the student forward.
  • Course Final Exam Capstone: A celebratory final milestone badge that unlocks exclusively once all preceding lessons are completed.

2.2 The Quiz & Assessment Engine

Assessment integrity is maintained by decoupling testing from rote memorization:

  • Randomized Question Sampling: Rather than presenting fixed static tests, the engine queries the question bank and extracts a randomized subset for each attempt.
  • Atomic Scoring & Instant Evaluation: Answer submissions are graded server-side against protected cryptographic keys, immediately calculating percentage accuracy and awarding earned XP.
  • Mastery Unlocking Trigger: Upon attaining the passing benchmark, the backend transactionally updates lesson_progress, unlocks the subsequent lesson, and triggers a celebratory confetti celebration.

2.3 Gamification, Streaks & Rank Tiers

Tier Name XP Threshold Visual Badge Privileges & Status

Intermediate 200 – 499 XP Intermediate Demonstrated consistency across multiple completed lessons.
Advanced 500 – 999 XP Advanced Proficient student completing full curriculums and final exams.

Daily Streak Engine: Evaluates login frequency daily. Consecutive logins increment the streak counter, displaying a fire badge in the navigation header. Missing more than 48 hours automatically resets the streak, reinforcing daily discipline.

3 Instructor Suite & Curriculum Authoring

3.1 Executive Analytics & Drop-off Funnel

Instructors are provided with a dedicated administrative dashboard delivering actionable curriculum insights:

  • Telemetry KPIs: Total enrolled students, overall curriculum completion rate, active course counts, and system-wide quiz average.
  • Per-Lesson Drop-off Funnel: A visual Chart.js funnel chart plotting completion ratios across each lesson in a sequence. Instructors can instantly identify specific lessons where student completion drops, highlighting ambiguous content or overly difficult quiz questions.
  • Student Engagement Directory: Detailed roster tracking student progress, individual XP balances, and enrollment dates.

3.2 The 3-Mode Content Studio

Located at studio.html, the Content Studio provides a comprehensive visual curriculum authoring suite:

1. Visual Form Mode

Non-technical instructors build structured lessons using clean fields: Introduction, Main Concept, Code Samples, Takeaways, and External Links.

2. Live Preview Mode

Real-time WYSIWYG rendering displaying YouTube video embeds, formatted typography, and prose exactly as a student sees it.

3. Raw HTML Mode

Power-user code editor with direct syntax access for advanced custom styling, iframes, and interactive embeds.

3.3 Course Publishing Lifecycle & Question Bank

Courses support a dual-state lifecycle: Draft and Published. Draft courses remain completely invisible to students, allowing instructors to build out curriculum, order lessons with reorder buttons (Move Up / Down), and seed question banks before making the course live with a single click.

4.1 Technology Stack Rationale

Component Technology Engineering Rationale
Runtime Node.js (v18+) Asynchronous non-blocking event loop ideal for concurrent API requests and real-time quiz evaluations.
Web Framework Express 5.x High-performance, unopinionated routing engine with native modern promise handling.
Relational Database MySQL 8.x Strict referential integrity, foreign key cascading, and ACID transactions essential for the XP ledger.
Connection Pool mysql2/promise Prepared statement execution preventing SQL injection and connection pooling handling high concurrent loads.
Security bcryptjs & JWT Salted password hashing (cost factor 10) and signed stateless token validation without session storage overhead.
Frontend Vanilla JS + Tailwind Zero bloated virtual DOM overhead; lightning-fast page transitions and full control over animations.

The relational database schema is structured under third normal form (3NF) with enforced foreign key cascades:

course_idINTFK -> courses.id ON DELETE CASCADEAssociated parent course curriculum.
positionINTNOT NULLSequential step ordering index (1, 2, 3...).
titleVARCHAR(200)NOT NULLLesson topic title.
duration_minutesINTDEFAULT 20Estimated lesson reading/video duration.

5.4 Tables: quiz_questions & lesson_progress

Table Key Columns Function & Relationships
quiz_questions id, course_id, lesson_id, quiz_type, question_text, options, correct_answer Stores question text, JSON array of options A-D, and correct key. quiz_type differentiates lesson quizzes from course final exams.
lesson_progress user_id, lesson_id, passed_quiz, completed_at Tracks exact user state per lesson. passed_quiz = 1 unlocks the next lesson in sequence.
enrollments user_id, course_id, enrolled_at, is_completed Maintains user course registration. is_completed = 1 is set upon passing the final exam.
xp_transactions user_id, amount, reason, created_at Immutable financial ledger auditing all XP credits (quiz rewards, bonus XP) and debits (course enrollments).

7 Security Architecture & Operational Guide

🔒 Security Controls

  • Cryptographic Passwords: All credentials hashed using bcrypt with salt rounds = 10.
  • Stateless JWT Validation: Protected routes require signed Bearer tokens with 7-day expiration.
  • SQL Injection Immunity: 100% of database queries execute via parameterized prepared statements.
  • Sequential Gatekeeping: Server-side validation ensures students cannot access Lesson N without passing Lesson N-1.

⚡ Performance & Scalability

  • Connection Pooling: Express utilizes mysql2/promise pool with automatic connection recycling.
  • Optimized Static Assets: Frontend assets bundled cleanly with CDN fonts and instant rendering.
  • Database Indexing: Unique constraints on users.email and composite indexes on (user_id, course_id).
  • Atomic XP Transactions: Balance modifications execute within transactional boundaries.
